# Page Structure & Editorial Layout Reference

## Global Navigation & Controls (All Pages)
- **Header Links**: `Home 1` | `Home 2` | `Products` | `Festive Edit` | `Contact` | **[Shop Collection]** CTA
- **Utility Controls**: Dark/Light Mode Toggle (`.js-theme-toggle`), RTL/LTR Toggle (`.js-rtl-toggle`), Mobile Drawer (`.js-menu-open`).
- **Accessibility**: `.skip-link` as first focusable element, single semantic `<h1>` per page, `aria-live` status regions for filters and form messages.
