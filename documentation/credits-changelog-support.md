## 2. Changelog

### Version 1.0.0 — 2026-11-05
- Initial production release of Zariya Women's Ethnic Wear Boutique website.
- Added 5 primary pages (`index.html`, `home-2.html`, `products.html`, `festive-edit.html`, `contact.html`) and 2 utility pages (`404.html`, `coming-soon.html`).
- Implemented custom 3D perspective card tilt plugin (`assets/js/plugins/tilt.js`) with touch fallback and strict centered card alignment.
- Implemented Dark/Light theme persistence (`dark-mode.css`) and full Right-to-Left layout support (`rtl.css`).
- Added multi-facet product filtering, 18 sub-category quick filters, price sorting, skeleton loaders, and zoomable Product Details & Styling modal.

## 3. Support & Maintenance
For technical customization assistance:
1. Check `documentation/customization-guide.md` for colour tokens, typography swaps, and Formspree/Mailchimp hooks.
2. Search the repository for `TODO:` comments to verify all store-specific placeholders have been replaced prior to launch.
3. Validate HTML and structured data after content edits using the W3C Nu Html Checker and Google Rich Results Test.
