ZARIYA BOUTIQUE — LOCAL SELF-HOSTED FONTS DIRECTORY
===================================================
Typography defaults to Google Fonts (Cormorant Garamond, Jost, and Pinyon Script) loaded with preconnect hints in each HTML document <head>.

To self-host WOFF2 font files offline:
1. Place CormorantGaramond-*.woff2, Jost-*.woff2, and PinyonScript-Regular.woff2 in this directory (assets/fonts/).
2. Declare @font-face rules at the top of assets/css/style.css pointing to ../fonts/<filename>.woff2.
